# v2.1.0 周课表与课程详情

登录后直接显示七天周课表，以星期为列、节次为行；点击课程进入详情页查看基本信息并操作单门签到。登录表单、账号记忆和网络模式沿用此前实现。一键签到入口、确认对话框及控制器操作已移除。

## 展示与操作

- 使用本应用原有蓝白配色、水彩校园素材与 Compose 控件，课程按连续节次占据相应高度。
- 保留周次选择、前后周、本周定位、刷新、中英文及运行日志。
- 课程详情显示实际课程名称、课程号、日期与星期、起止时间、节次、地点、教师、排课号和签到状态。缺失字段显示待定，不生成虚构信息。
- 同时段重叠的课程可以分别选择；不能精确对应标准节次的课程列在网格之外，仍可进入详情。
- 详情读取当前课表中的课程状态；签到后随刷新更新，忙时不能重复提交。切换周次、退出或课程从最新课表中消失时，不保留旧课程的可操作详情。
- 教务课表对照继续用于过滤 iClass 残留排课，课表详情展示其核对状态。尚未核对的课程由用户确认后逐门操作。

当前展示数据来自 iClass，经过 GSMIS 对照过滤。这样保留学校返回的实际排课 ID、上课时间及签到状态，不把另一个系统的教学班号当作签到 ID。课表只查询与显示，不会因打开课程详情自动签到。

## 接口兼容

GSMIS 兼容修正允许课程名称 `KCMC` 来自教学任务或排课记录，双方均提供时须一致；名称缺失或互相冲突仍视为不完整数据。真实账号和学校接口仍需要在手机环境验证，模拟测试及界面渲染不能替代真机验证。
